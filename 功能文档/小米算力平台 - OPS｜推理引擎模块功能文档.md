# 小米算力平台 - OPS｜推理引擎模块功能文档

#

> 模块定位：运行时 - 推理引擎管理，用于推理引擎安装包版本上传、元数据配置、校验、生命周期管控，为【模型】模块提供可绑定的运行引擎依赖包。
>
> 交互说明：点击页面右上角**上传版本**按钮，唤起【上传推理引擎】弹窗（模态弹窗，浮于列表之上）。

## 一、推理引擎列表页

### 1. 页面基础信息

* 入口：左侧菜单【推理引擎】
* 顶部状态链路：`上传中 → 校验中 → 待上架 → 已上架`
* 筛选控件：引擎下拉、状态下拉，支持按引擎标识、版本状态过滤列表
* 主操作按钮：右上角橙色【上传版本】，唤起上传弹窗
* 顶部核心提示规则：

> 选择安装包时会先读取压缩包大小和入口，并计算 sha256。上传后的「校验中」只核对对象大小，并读取压缩包末尾的目录确认入口，不会把整个安装包下载回来。校验中可以终止或删除。多个已上架版本会同时提供给客户端，新上架版本必须高于当前已上架的最高版本。

### 2. 列表表格字段

表格

| **字段** | **说明**                               |
| ------ | ------------------------------------ |
| 引擎     | 引擎唯一标识，如 OpenVINO ovms；同一引擎下维护多条版本   |
| 版本     | 语义化版本号；上架强约束：新版本必须大于该引擎当前**已上架最高版本** |
| 协议     | 协议编号，客户端兼容标识（桌面端仅支持协议 2）             |
| 最低客户端  | 版本兼容门槛，控制哪些客户端可以加载该引擎包               |
| 平台     | 目标运行架构，示例：windows/amd64              |
| 状态     | 版本生命周期：校验中 / 失败 / 待上架 / 已上架 / 已下架    |
| 大小     | zip 安装包体积                            |
| 更新     | 该版本最后操作时间                            |
| 操作     | 根据状态动态渲染操作按钮                         |

### 3. 状态机 & 对应操作

表格

| **状态** | **展示内容**                    | **可用操作**    | **说明**                    |
| ------ | --------------------------- | ----------- | ------------------------- |
| 校验中    | 展示校验日志、报错链路（如 IO 超时、存储请求日志） | 编辑、终止校验、删除  | 轻量化校验，不下载完整包；可主动中断校验流程    |
| 失败     | 展示失败原因日志                    | 编辑、删除       | 校验异常，不可上架；修改配置 / 包后重新提交校验 |
| 待上架    | -                           | 编辑、上架、吊销、删除 | 校验通过，等待对外发布；执行上架时会校验版本号规则 |
| 已上架    | -                           | 编辑、吊销、删除    | 对外提供给客户端；同引擎允许多个版本同时上架    |
| 已下架    | -                           | 编辑、删除       | 吊销后状态，不再向客户端分发该引擎包        |

### 4. 列表操作释义

1. **上传版本**：唤起【上传推理引擎】弹窗，新增一条引擎版本记录
2. **编辑**&#x20;
   1. 校验中 / 失败 / 待上架：全部字段可修改，保存后重新触发校验
   2. 已上架版本：仅【说明】字段可修改；协议、最低客户端、包、能力、版本号等兼容性字段冻结，如需变更只能上传更高版本
3. **终止校验**：仅校验中可用，中断当前校验任务
4. **上架**：仅待上架可用；校验版本号合法性，通过后变更为已上架
5. **吊销**：待上架 / 已上架可用，执行下架，转为已下架状态
6. **删除**：所有状态支持删除；已上架版本删除建议增加强二次确认，避免模型依赖断裂

### 5. 和模型模块联动规则

1. 上传模型弹窗内【推理引擎】下拉数据源为本模块**已上架**引擎版本
2. 模型表单【引擎最低版本】联动：先选客户端最低版本，引擎下拉只过滤：已上架、引擎「最低客户端版本 ≤ 模型选中的客户端最低版本」
3. 引擎吊销下架后，绑定该引擎版本的模型无法在客户端正常调度运行

## 二、上传推理引擎弹窗文档

> 触发方式：推理引擎列表右上角【上传版本】按钮，弹出模态弹窗，弹窗内纵向滚动，底部固定「取消 / 上传并校验」按钮。
>
> 弹窗顶部提示文案：
>
> 当前发布 windows/amd64 的 stable 通道。修改入口路径、解压后大小，或重新选择 zip，保存后会核对对象大小，并读取压缩包末尾的目录确认入口。只改说明、协议、最低客户端或能力时沿用上次校验结果。

### 1. 字段总表

表格

| **字段**     | **必填** | **控件**           | **规则 & 提示文案**                                    |
| ---------- | ------ | ---------------- | ------------------------------------------------ |
| 选择 zip 安装包 | 是      | 文件选择区域           | 仅支持 zip 包；重新选择 zip，系统会**重新读取包大小、入口，重新计算 sha256** |
| 推理引擎       | 是      | 下拉选择             | 选择归属引擎标识（如 OpenVINO ovms）                        |
| 版本号        | 是      | 输入框              | 语义化版本（例：2026.5.0）；上架时强制校验：版本号高于该引擎当前已上架最高版本      |
| 协议号        | 是      | 输入框              | 客户端通信协议，桌面端只安装协议 2，固定兼容约束                        |
| 最低客户端版本    | 是      | 下拉选择（从客户端版本目录选取） | 控制客户端兼容下限，作为模型侧联动过滤依据                            |
| 入口路径       | 是      | 输入框              | 压缩包内可执行文件相对路径；切换引擎自动填充默认入口，支持手动修改                |
| 解压后字节数     | 是      | 输入框              | zip 解压之后总字节大小；选包后自动解析带出，也支持手动修改                  |
| 能力         | 是      | 复选框组             | 可选：流式、工具调用、视觉、音频输入、音频输出、推理强度；决定引擎对外支持的能力集        |
| 说明         | 否      | 多行文本             | 备注描述，上架后唯一允许编辑的字段                                |

### 2. 弹窗内置联动规则

1. **包变更触发重校验**：重新选择 zip 包、修改入口路径、修改解压后字节数 → 保存时触发完整校验（读取压缩包尾目录核对入口、比对大小）
2. **仅元信息变更，复用上次校验结果**：只修改【说明、协议号、最低客户端版本、能力】，不更换 zip 包、不改入口 / 解压大小 → 不再重新做包校验，直接沿用之前的校验结果，提升提交效率
3. 平台信息：平台（windows/amd64）跟随 zip 包所属 stable 通道自动带入，表单不可编辑

### 3. 提交链路

弹窗底部操作：

* 取消：关闭弹窗，丢弃当前表单填写内容
* 上传并校验：主橙色提交按钮；提交后进入上传流程，流转到列表【上传中】→【校验中】状态

### 4. 包校验机制（统一规则）

1. 选包阶段：前端读取 zip，读取入口文件、计算 sha256 指纹、读取包大小
2. 服务端校验阶段：**不下载完整压缩包**，仅校验两点：①对象大小匹配 ②读取压缩包末尾目录校验入口路径合法性；带宽开销低、校验速度快
3. 校验失败：自动流转到【失败】状态，在列表透出原始请求链路、IO / 存储类报错日志，方便排查

## 三、整体补充约束与待确认项

1. 版本对比：严格语义化版本比较，低版本号不允许上架
2. 吊销后存量客户端：待确认，已下载引擎包的客户端是否继续可用
3. 删除风险：删除已上架引擎会影响依赖该引擎版本的线上模型，建议增加风险提示弹窗
4. 无草稿：弹窗关闭后表单内容不自动保存
