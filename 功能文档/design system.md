# 小米 AI 算力平台 Design System

> 依据 `参考/` 目录下 6 张界面截图整理：使用统计、安全服务、模型商店、模型管理、设置弹窗、用户中心。
> 数值为从截图目测得到的近似值，实现时以设计稿为准。

---

## 1. 设计方向

- **风格关键词**：轻盈、干净、桌面端工具感、柔和玻璃卡片、留白充足。
- **整体气质**：浅灰底 + 白色悬浮卡片 + 单一蓝色主色，角落有极淡的暖色/冷色渐变光晕，营造氛围而不抢内容。
- **信息组织**：左侧固定导航 + 右侧内容区；内容以卡片分组，数据以大数字 + 环形/进度条呈现。

---

## 2. 应用框架

| 区域 | 规格 |
|---|---|
| 窗口 | 桌面窗口，参考尺寸约 1020 × 748，圆角约 10px |
| 标题栏 | 高度约 48px，背景同页面底色；左侧 Logo + 应用名"小米 AI 算力平台"；右侧依次为设置图标、最小化、最大化、关闭 |
| 侧边栏 | 宽度约 200px，背景 `#F5F6F8`，右侧有 1px 分隔线 `#E8EAEE` |
| 内容区 | 背景 `#FAFAFB`，叠加低透明度渐变光晕；左右内边距约 60px（内容起点距侧栏约 60px），顶部约 36px |
| 内容最大宽 | 内容横向铺满，右侧留白与左侧对称（约 66px） |

### 侧边导航

- 顺序固定：用户中心 → 使用统计 → 模型商店 → 模型管理 → 安全服务
- 每项：左侧 18px 线性图标 + 文字 14px，高度约 32px，左对齐，项间距约 4px，容器内边距 `0 12px`
- 默认：文字 `#1F2329`，图标同色
- 悬停：背景 `#ECEEF2`，圆角 8px
- 选中：背景 `#E4EEFD`，文字与图标为主蓝 `#2F7BFF`，圆角 8px

### 3.1 基础色

| Token | 色值 | 用途 |
|---|---|---|
| `--color-primary` | `#2F7BFF` | 主操作按钮、选中态文字、链接 |
| `--color-primary-hover` | `#1F6AEE` | 主按钮悬停 |
| `--color-primary-soft` | `#E4EEFD` | 选中导航背景、标签背景 |
| `--color-bg-app` | `#FAFAFB` | 页面底色 |
| `--color-bg-sidebar` | `#F5F6F8` | 侧栏底色 |
| `--color-surface` | `#FFFFFF` | 卡片、弹窗 |
| `--color-surface-glass` | `rgba(255,255,255,0.7)` | 半透明卡片（数据表格容器） |
| `--color-border` | `#E8EAEE` | 分割线、表格线 |
| `--color-text-primary` | `#1F2329` | 标题、正文主要信息 |
| `--color-text-secondary` | `#6B7280` | 描述、标签文字 |
| `--color-text-tertiary` | `#9AA0A9` | 辅助信息、表头 |
| `--color-text-danger` | `#E5484D` | 删除等危险操作 |

### 3.2 数据可视化色

| Token | 色值 | 用途 |
|---|---|---|
| `--chart-blue` | `#3B82F6` | GPU 利用率环、占比条 |
| `--chart-purple` | `#8B5CF6` | GPU 第二项环、占比条 |
| `--chart-cyan` | `#22D3EE` | GPU 第三项环、占比条 |
| `--chart-track` | `#EEF0F3` | 环形/进度条底轨 |

### 3.3 状态色

| 状态 | 文字 | 背景 |
|---|---|---|
| 运行中 | `#16A34A` | `#E6F7EE` |
| 未加载 | `#6B7280` | `#F0F1F3` |
| 标签（功能分类） | `#2F7BFF` | `#EAF2FF` |
| 开关开启 | 轨道 `#22C55E` | — |
| 开关关闭 | 轨道 `#D5D9E0` | — |

### 3.4 氛围光晕

- 内容区背景右下、左下处叠加极淡的径向渐变（暖橙、薄荷绿、淡蓝），透明度 ≤ 15%，只作背景装饰，不得影响文字对比度。

## 4. 字体与排版

字体栈建议：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", system-ui, sans-serif`；数字可使用同族字体，保证中英混排统一。

| 层级 | 字号 / 字重 | 行高 | 示例 |
|---|---|---|---|
| 页面大标题 | 20px / 600 | 28px | 安全服务、使用统计 |
| 区块标题 | 18px / 600 | 26px | 硬件利用率、Key管理、超级小爱 |
| 卡片标题 | 16px / 600 | 24px | GPU、模型名称 |
| 大数字（金额） | 32px / 600 | 40px | ¥1,286.40 |
| 指标数值 | 20px / 600 | 28px | 2.4 M、1,284 次 |
| 环形百分比 | 20px / 600 | — | 68% |
| 正文 | 14px / 400 | 22px | 导航、表格内容、按钮 |
| 辅助说明 | 12px / 400 | 18px | 显存 5.2 / 8 GB、发布日期 |
| 表头 | 12px / 400 | 18px，色 `--color-text-tertiary` | 名称、密钥、创建时间 |

数字类信息（Token、次数、延迟、版本号）使用等宽或tabular-nums，保证右对齐时位数整齐。

---

## 5. 间距与圆角

**间距刻度**（4px 基数）：4 · 8 · 12 · 16 · 20 · 24 · 32 · 36 · 60

| 场景 | 值 |
|---|---|
| 卡片内边距 | 20–24px |
| 卡片之间水平/垂直间距 | 16px（小卡）/ 20px（大卡） |
| 区块之间垂直间距 | 32px |
| 标题与内容间距 | 12–16px |
| 表格单元格内边距 | 行高 44px，左右 16px |

**圆角**

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 小标签、输入框内小按钮 |
| `--radius-md` | 8px | 按钮、导航项、输入框 |
| `--radius-lg` | 12px | 小卡片、指标卡 |
| `--radius-xl` | 16px | 主卡片、表格容器、弹窗 |
| `--radius-pill` | 999px | 开关、分段控件、标签 |

---

## 6. 阴影与层次

- 卡片：`box-shadow: 0 1px 2px rgba(16,24,40,0.04), 0 4px 16px rgba(16,24,40,0.04)`，几乎贴地，不做厚重投影。
- 弹窗：`box-shadow: 0 12px 48px rgba(16,24,40,0.16)`，遮罩 `rgba(0,0,0,0.35)`。
- 卡片边框：默认无边框；仅在需要分层时使用 1px `#EEF0F3`。

---

## 7. 组件规范

### 7.1 按钮

| 类型 | 高度 | 样式 |
|---|---|---|
| 主按钮（添加key、启用、导入推荐配置） | 36px | 背景 `--color-primary`，白字 14px/500，圆角 8px，左右内边距 16px |
| 次按钮（复制、停止、管理、配置） | 32–36px | 背景 `#F2F3F5`，文字 `#1F2329`，圆角 8px |
| 浅主按钮（测试、检查） | 32px | 背景 `--color-primary-soft`，文字 `--color-primary` |
| 危险文字按钮（删除） | 30px | 白底、1px 边框 `#F0D0D1`，文字 `#E5484D`，圆角 8px |
| 图标按钮（设置、关闭、窗口控制） | 32 × 32px | 透明底，悬停背景 `#ECEEF2` |

> 同一界面内的按钮高度保持一致（同一行统一 36px 或统一 32px）。

### 7.2 开关 Switch

- 尺寸：宽 40px、高 22px，圆形滑块 18px
- 开启：轨道绿色 `#22C55E`，滑块居右
- 关闭：轨道灰色 `#D5D9E0`，滑块居左

### 7.3 分段控件 Segmented

- 外层白底圆角 pill，内边距 2px，选中项白底 + 轻阴影，文字主色加粗
- 用于 "局域网 / 本地"、"GPU / NPU"

### 7.4 标签 Tag / Badge

- 功能标签（通用问答、编程）：高 20px，背景 `#EAF2FF`，文字 `#2F7BFF`，12px，圆角 4px
- 状态徽标（运行中、未加载）：高 20px，圆角 4px，见 3.3 状态色

### 7.5 Tab 页签（模型管理）

- 文字 16px，未选中 `#9AA0A9`，选中 `--color-text-primary` 并带 2px 下划线
- 与列表之间留 20px 间距

### 7.6 筛选 Chip

- 高 28px，圆角 pill，内边距 `0 12px`，12–13px 文字
- 未选中：白底 `#FFFFFF` + 无边框，文字 `#4B5563`
- 选中：背景 `--color-primary-soft`，文字 `--color-primary`

### 7.7 输入框与搜索

- 高 36px，白底，圆角 8px，无边框或 1px `#E8EAEE`，聚焦时蓝色 1px 描边
- 搜索框前缀放大镜图标，占位文字 `#9AA0A9`
- 数字输入（上下文长度、空闲分钟数）宽约 72px，右对齐

### 7.8 滑块 Slider

- 轨道高 4px，已填充段 `--chart-blue`，未填充 `--chart-track`
- 拇指 14px 白色圆点，带 1px 灰色描边与轻阴影
- 右侧显示当前值（如 1.0x、12）

### 7.9 下拉选择

- 高 32–36px，白底，圆角 8px，1px 边框 `#E8EAEE`，右侧 chevron 图标
- 下拉面板风格需与首页文件选择下拉保持一致

### 7.10 指标卡（使用统计）

- 白底卡片，圆角 12px，内边距 16–20px
- 结构：左侧标题（12–14px 灰）+ 数值（20px 粗）+ 单位（12px）；右侧 32px 方形浅蓝图标块（`#E4EEFD`，圆角 8px）
- 4 个指标卡等宽、横向排列，间距 12–16px

### 7.11 硬件利用率卡（环形图）

- 三卡等宽横向排列，左侧文本（标题 16px、说明 12px 两行）、右侧环形图
- 环形直径约 80px，线宽约 8px，圆端，底轨 `--chart-track`
- 中心百分比 20px 粗体；环颜色依次为 蓝 / 紫 / 青

### 7.12 金额横幅

- 白色大卡片，高约 112px，左侧 3D 风格插画（钱包），中部"本月为您节省约"（12px 灰）+ 金额（32px 粗），右侧金币装饰插画
- 插画装饰仅出现在此类 Hero 卡片中，不在普通卡片中滥用

### 7.13 数据表格

- 容器：白色半透明圆角 16px 卡片，内边距 `0 20px`
- 表头：12px 灰色，无背景；行高 44px；行间 1px `#EEF0F3`
- 占比列：进度条宽约 80px，高 6px，圆角 pill，颜色对应图表色，右侧显示百分比
- 数字列右对齐（或统一左对齐，同一表格保持一致）

### 7.14 列表卡（Key 管理 / 安全服务）

- 容器同数据表格；行内容左对齐，操作列靠右放置危险按钮
- 密钥做脱敏展示，中间以 `....` 省略

### 7.15 模型卡（模型商店 / 模型管理）

- 商店卡：宽度等分三列，间距 12–16px，白底圆角 16px，内边距 20px
  - 结构：模型名 16px 粗 → 标签 → 描述 13px 灰 → 元信息行（发布日期 / 大小）12px → 底部全宽主按钮"待下载"
- 管理卡：两列，同样白底圆角 16px；标题行含名称 + 状态徽标 + 功能标签；下方为参数网格（运行框架 / 文件大小 / 量化版本，标签灰 12px、值 14px）；底部为参数控件区，操作按钮位于右上
- 同一行卡片高度对齐

### 7.16 设置弹窗（Dialog）

- 宽约 590px，白色，圆角 16px，遮罩 35% 黑
- 内边距 32px；标题 20px 粗；分组标题 13px 灰
- 列表项：背景 `#F5F6F8`，圆角 10px，高约 56px，右侧 chevron 图标
- 关闭按钮位于右上角
- **尺寸约束**：弹窗最大高度 600px；当视口高度小于 750px 时，高度自适应为视口的 80%

### 7.17 用户中心配置卡

- 基础服务条：白色整行卡片，左侧名称 + 说明，右侧开关
- 双栏卡：本地大模型（2×2 小方块，内含服务名 + 模型名）与云端大模型（进度条 + 状态"已连接"绿点）
- 超级小爱：三张等宽功能卡，左文字 + 右侧 3D 插画
- 智能体卡：三列，顶部头像 + 名称，底部两枚等宽次按钮（管理 / 配置）

---

## 8. 图标

- 线性图标，描边 1.5px，尺寸 16px（小）/ 18px（导航）/ 20px（卡片内）
- 颜色跟随文字色，选中态跟随主色
- 卡片装饰图标使用浅蓝底的方形容器（32px，圆角 8px）

---

## 9. 插画与装饰

- 仅在 Hero / 功能入口卡中使用 3D 风格小插画（钱包、金币、人物、文件夹、笔记本）
- 插画风格：柔和光影、低饱和蓝紫与金色为主
- 生成插画需遵循项目图片规范；不得使用占位图

---

## 10. 动效

- 按钮/导航悬停：`background-color 150ms ease`
- 开关：滑块位移 `200ms ease-out`
- 环形图与进度条：首次渲染 `600ms ease-out` 从 0 增长
- 弹窗：淡入 + 轻微上移 8px，`200ms`
- 避免无意义的持续动画

---

## 11. 布局规则（来自既有偏好）

- 按钮高度在同一界面内保持一致
- 弹窗最大高度 600px，视口较小时为视口高度的 80%
- 对话类页面：输入框固定在底部，距底边 16px，聊天内容位于输入框上方
- 文字对比：`.mt-trans-text` 在浅色模式为黑色、深色模式为白色
- 下拉菜单需与首页文件选择下拉的样式一致
- 页面标题与字号需与路由配置页保持一致
- 表单区域顶部留白按需收紧（如邮箱、验证码输入框顶部 padding 8px）
- 小字提示文本与主文本左对齐

> **注意**：用户偏好中提到"按钮采用黑白配色、透明底、悬停半透明"，而参考截图的主操作按钮为蓝色 `#2F7BFF`。当前文档以截图为准；若需要切换为黑白按钮，请确认后在 `--color-primary` 与按钮规范中统一调整。
