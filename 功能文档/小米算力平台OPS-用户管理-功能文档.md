## 一、功能定位

「用户」模块用于管理**运营控制台的账号台账与角色归属**，是角色权限体系的数据来源。

平台上的账号统一在此登记并分配角色，与登录方式无关：**OA 账号与本地账号同表管理**，只是来源不同。

对应能力边界：

- 本模块只负责账号本身的创建、编辑、状态与删除，以及**角色分配**。
- 角色本身的定义与权限范围（能访问哪些菜单、能操作哪些功能）由「角色权限」模块承担（推断）。
- 本模块不涉及 SSO/OA 侧的账号生命周期本身的创建，OA 账号为同步引入（推断）。

3. 本地账号的密码由平台管理（新建时设置、编辑时可重置）；OA 账号的密码校验应走 OA 侧（推断，编辑页仍提供"重置密码"能力，需确认其对 OA 账号是否生效）。

## 五、功能点

### 1. 新建用户

表单要素：

| 字段 | 必填 | 说明 |
|---|---|---|
| 账号 | 是 | 登录标识（工号），需唯一 |
| 显示名 | 是 | 人员姓名 |
| 邮箱 | 否 | 通知与联系用；OA 账号为 `工号@xiaomi.com` |
| 密码 | 是 | 初始登录密码 |
| 角色 | 否（推断） | 可创建后补配；不填则无任何权限 |

行为：

- 保存后账号入库，状态为启用（推断），创建时间即时记录。
- 取消则丢弃输入，不落库。

### 2. 编辑用户

可编辑项：显示名、邮箱、**重置密码**、状态、角色。

不可编辑项：工号（账号标识）、来源、创建时间。

规则：

1. **密码重置为可选**：不填写即保持原密码不变，填写则覆盖（编辑页该字段为空且为掩码占位，符合"留空不改"的惯例）。
2. **状态切换**：可在启用 / 停用间切换，停用后账号不可登录（推断）。
3. **角色调整**：可新增或移除（标签带删除标记），保存后即时生效。
4. 编辑不改变账号的创建时间与来源属性。

### 3. 状态管理

- 状态是账号级别的可用开关，与密码、角色相互独立。
- 停用不等于删除：停用保留台账记录与历史，可再次启用（推断）。
- 列表默认全部展示，未见按状态筛选能力（见第六节）。

### 4. 删除账号

- 删除为**二次确认**操作，确认弹层显式询问"删除这个账号？"，可选取消或确定。
- **超级管理员账号受保护**：其删除入口置灰不可用，防止误删导致控制台失去管理入口。
- 删除为**物理删除还是逻辑删除**未体现，需确认（物理删除将不可恢复，逻辑删除则保留追溯）（推断：建议逻辑删除并留痕）。

### 5. 列表与分页

- 台账以分页形式展示，当前仅 1 页（5 条记录）。
- 未提供关键字搜索、按来源/角色/状态筛选、批量操作能力。

## 六、现有功能能力与缺口

已具备：

- OA 与本地两类账号的统一台账管理。
- 账号新建、编辑、删除、状态启停。
- 账号级角色分配（可多角色）。
- 密码重置能力。
- 超级管理员的删除保护。

尚不具备或未体现：

- 账号检索（按工号/姓名/部门搜索）与按来源、角色、状态的筛选。
- 批量操作（批量停用、批量改角色）。
- 组织架构维度的管理（部门仅作展示字段，无法按部门批量分配）。
- 账号操作审计（谁在何时创建/修改/删除了账号，未与使用日志打通，需确认）。
- 密码策略（复杂度、过期、首次登录强制改密）未见。
- OA 账号注销后的同步处理规则（OA 离职后控制台账号是否自动停用）未见。
