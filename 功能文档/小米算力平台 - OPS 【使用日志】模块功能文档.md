# 小米算力平台 - OPS 【使用日志】模块功能文档

#

## 1. 模块定位

使用日志是平台**审计溯源模块**，用于记录、检索平台内模型 / 推理引擎的调用使用行为、用户操作流水，支撑问题排查、用量统计、安全审计、对账追溯；和元数据、模型、推理引擎模块联动，是全链路行为凭证。

> 侧边导航独立菜单，和【模型、推理引擎、元数据、审批、用户、角色权限】平级。

## 2. 核心能力

1. **日志采集**：自动记录算力推理调用、模型加载、推理请求、用户在控制台的关键操作行为；绑定操作者、时间、模型 / 引擎、机型、客户端信息。
2. **多条件检索过滤**：支持时间范围、操作用户、模型标识、推理平台、适配机型、客户端版本、日志状态 / 结果筛选，快速定位目标记录。
3. **日志明细查看**：单条日志可展开详情，查看请求参数、返回结果、耗时、报错信息、设备硬件信息、sku、平台代号，用于定位推理失败、异常报错、性能问题。
4. **导出能力**：支持日志列表导出，用于离线对账、报表、合规留档。
5. **只读审计**：日志仅可查询、查看、导出，**不支持编辑、删除**，保证审计数据不可篡改。

## 3. 页面结构

* 顶部：筛选区（时间选择器、用户下拉、模型、推理平台、机型、状态等筛选条件 + 查询、重置、导出按钮）
* 中间：日志列表表格，基础列：**时间、操作用户、模型名称 / 编码、推理平台、适配机型、客户端版本、行为类型、结果状态、耗时、操作**
* 操作列：【查看详情】按钮，唤起弹窗展示完整原始日志内容（请求报文、错误栈、硬件信息、sku\_code、device.platform 等）

## 4. 和其他模块联动关系

* 关联**元数据**：日志里的机型、推理平台、客户端版本、标签、推理强度，取值来自元数据字典；日志会记录实际匹配到的机型配置编码。
* 关联**模型 & 推理引擎**：日志绑定模型 ID、引擎版本，可追溯是哪个模型包、哪个引擎版本产生的推理调用。
* 关联**用户 & 角色权限**：日志记录操作人账号；权限控制：仅拥有审计权限角色可以访问使用日志、查看明细、导出。
* 关联**审批**：审批流转动作也会写入使用日志，形成完整变更审计链。

## 5. 业务用途

* 故障排查：用户推理报错、模型加载失败，通过日志查看原始报错、设备匹配情况；
* 用量统计：统计不同机型、不同模型的推理调用频次；
* 安全审计：追溯谁、在什么时间，调用了哪个模型；
* 合规留痕：所有调用行为持久化留存，不可修改删除；
* 版本灰度验证：观察新机型 / 新客户端版本下模型调用成功率。
